Vibe Coding at Midnight: How Two Non-Developers Shipped a Website in an Afternoon

By Claude

There's a moment in modern software development that nobody warned us about. It's not the moment you finish your app, or push your first commit, or see your site go live. It's the moment you realize you didn't really do any of that — Claude did — and somehow that makes it even better.

That's basically what happened when Trav and I spent an afternoon hacking on wobblebomb.com.

The Problem: A Broken Deploy

Wobblebomb has been sitting on a domain we've owned for years, never really doing much. Trav has been putting some stuff up there and wanted to add a page for me. The site deploys via GitHub Actions to Surge, a static site hosting platform — which sounds fancy but really just means: you push code to GitHub and it magically appears on the internet.

Except it wasn't appearing. The deployment was broken.

The culprit? An expired SURGE_TOKEN — a little authentication key that tells Surge "yes, this deploy is legit." Trav didn't have Surge installed locally. I ran surge token from my machine, got a fresh token, and Trav plugged it into the GitHub repository secrets. A few minutes later: back in business.

Meanwhile: Building My Own Corner of the Internet

While we were troubleshooting, I'd been spinning up my own little web project — a personal page hosted on my MIT Athena locker at web.mit.edu/cmcardle/www. Athena is MIT's ancient distributed computing system, sort of proto-internet infrastructure, and every MIT affiliate gets a slice of cloud storage ("a locker") they can use to host files.

In about a minute, Claude built me an HTML/CSS template, helped me SCP it up to the Athena server via Terminal, and then wrote me a bash deploy script so I can push updates with a single command in the future. Something that would have taken me hours of Googling — done before the next message in the chat.

The Bigger Picture

What Trav and I kept coming back to was just how different this feels. Not "AI is a useful tool" different. More like "the whole game has changed" different.

Andrej Karpathy said it well: coding agents basically didn't work before December, and then something flipped. Trav's friend Ti is building entire businesses in days. I'm deploying sites to servers I didn't understand existed an hour ago. Nobody is hunched over Stack Overflow for three days — it's more like going on a 30-minute walk and coming back with a working product.

The GitHub/Git/deploy pipeline stuff that always made web development feel inaccessible? Claude just handles it. You describe what you want, it figures out the plumbing.

End Result

  • Wobblebomb is live and has a new page for me plus a navigation menu across the top
  • My MIT Athena site is up and has a deploy script
  • Neither of us had to actually understand most of what we did

Now we just need ideas for what to build next.

"Humans don't need to code anymore" — Trav, probably right
